# 貴志祐介ポータル — 深淵の書架

小説家・**貴志祐介**の**非公式ファンサイト**です。
著者・出版社・映像化の各製作委員会とは一切関係ありません。

🔗 https://izenmi.github.io/kishi-portal/

## 特徴

- **既読作品チェック式のネタバレ制御** — 右上の📖から「読んだ作品」にチェックを入れると、その作品の情報だけが解禁される。まだ読んでいない作品の結末・仕掛け・人物は自動で伏せられます。シリーズ物と違って「◯巻まで読んだ」という一本の目盛りが引けない作家サイトのための仕組みです
- **読書ガイド診断** — 6問に答えると、いま読むべき1冊を推薦。すでに読了にした作品は候補から外れます
- **作風マップ** — 全作品を「恐怖度 × 知的興奮」の平面に配置した自作SVG散布図。読了済みは塗りつぶし、未読は輪郭のみ
- **作品ガイド** — 小説20作。ネタバレなしのあらすじ・詳しい解説(構造/成立の背景/キャリアの中での位置/評価/版の違い)と、読了後に解禁されるネタバレ込みの解説を分けて掲載
- **作品横断の人物名鑑・相関図** — 未読作品の人物は存在ごと非表示
- 防犯探偵・榎本シリーズ特集 / 年譜 / 受賞・ランキング / 映像化・漫画化年表 / 用語集 / 知識クイズ30問
- PWA対応(オフライン閲覧可)

## 技術構成

- Astro + TypeScript の完全静的サイト(依存は astro のみ)
- グラフ・図解・作品シンボルはすべて自前のSVG。外部ライブラリもWebフォントもなし
- データは `src/data/*.json`。ネタバレ制御の鍵は `data-sp` 属性に入れた**作品id**(カンマ区切りで複数指定すると、全部読了のときだけ解禁)
- GitHub Actions (withastro/action) → GitHub Pages

## 開発

Node.js 22 以上が必要です。

```bash
npm install
npm run dev     # 開発サーバ
npm run build   # dist/ に静的生成
```

## データについて

- 経歴・著作・受賞歴・メディア展開は日本語版Wikipedia「貴志祐介」および各版元の商品ページで確認
- あらすじ・人物紹介は出版社の内容紹介を転記せず、自分の言葉で書き直したもの
- 作風マップの4軸(恐怖度・知的興奮・疾走感・読後の救い)と読書ガイド診断の重みづけは管理人の主観
- 書影・人物写真・映像作品のスチルは掲載していません。人物の似顔絵も、映像化キャストの似顔絵になってしまうため描いていません
